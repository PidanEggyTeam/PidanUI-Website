PidanUI 是一个由蛋仔爱好者发起的 **非盈利粉丝项目**，专注于在 Windows 桌面上实现《蛋仔派对》风格的视觉体验。本文汇总项目的基本信息与常见问题。

## 一、项目定位

- 非盈利、非商业的粉丝二次创作项目
- 不冒充官方，不与任何商业实体合作
- 所有美化内容通过主题包、壁纸、小组件等安全方式部署

> 如果你认同项目的定位，欢迎通过下方的贡献与反馈渠道加入我们。

## 二、项目构成

| 组成 | 说明 | 支持范围 |
| --- | --- | --- |
| 主题包 | 蛋仔风格 Windows 主题 | Windows 7 ~ 11 |
| Rainmeter 小组件 | 配套桌面小组件 | Windows 10 1607 ~ 11 |
| 辅助组件 | 基于 .NET 10 的辅助程序 | Windows 10 ~ 11 |
| 系统镜像 | 轻简版系统镜像 | 见发布公告 |

## 三、安装提示

安装前请确认：

1. 系统已开启必要的运行环境
2. 下载来源可信，校验文件完整
3. 按发布页的步骤逐项操作

示例校验命令：

```powershell
Get-FileHash .\PidanUI-3.5-Air.iso -Algorithm SHA256
```

## 四、常见问题

**Q：修改系统核心文件吗？**

A：不会。PidanUI 不替换 `imageres.dll.mun`、`shell32.dll.mun` 等系统文件，安装与卸载不影响系统稳定性。

**Q：会误报病毒吗？**

A：辅助组件已使用 .NET 10 重构，大幅降低杀软误报概率。
