PidanUI 的设计原则之一是**不修改系统核心文件**。

## 具体做法

- 不替换 `imageres.dll.mun`、`shell32.dll.mun` 等系统文件
- 通过主题包、壁纸、Rainmeter 小组件等方式实现美化
- 安装与卸载均不会影响系统稳定性

## 为什么这样做

替换系统文件虽然能实现更彻底的修改，但也带来了：

1. 系统更新后失效的风险
2. 卸载困难、难以恢复
3. 潜在的稳定性与安全风险

因此 PidanUI 选择了更安全的路线，让系统体验尽量接近原版 Windows。

> 安全与稳定，是 PidanUI 与用户之间的基本约定。
