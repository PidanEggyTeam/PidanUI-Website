```python
def fibonacci(n: int) -> list:
    """生成斐波那契数列"""
    a, b = 0, 1
    result = []
    for _ in range(n):
        result.append(a)
        a, b = b, a + b
    return result
```

> **提示**：以下是一个综合示例，用于检查多种元素混排时的间距。

1. 首先安装依赖：

   ```bash
   npm install
   ```

2. 然后修改配置文件：

   | 字段 | 值 |
   |------|-----|
   | `theme` | `default` |
   | `darkMode` | `true` |

3. 最后运行：

   ```bash
   npm run dev
   ```

   > 如果端口被占用，可通过 `--port` 指定。
