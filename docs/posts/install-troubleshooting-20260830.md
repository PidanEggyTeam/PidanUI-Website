安装过程中如遇到问题，可按以下步骤排查。

## 安装失败

- 确认镜像文件完整（校验哈希值）
- 确认启动模式与镜像匹配（UEFI / Legacy）
- 检查磁盘空间是否充足

## 主题未生效

- 确认已按提示重启资源管理器
- 检查是否被安全软件拦截
- 重新应用一次主题

## 性能异常

- 关闭不必要的小组件
- 检查是否为精简版系统的驱动问题

> 若以上方法无效，请通过反馈渠道联系我们，并附上系统版本与截图。
